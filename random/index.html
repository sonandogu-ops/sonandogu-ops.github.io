    공정하게 뽑아요

    보안 난수

    브라우저가 암호화에 쓰는 난수 기능으로 숫자를 뽑아요. 흔한 난수보다 예측하기 어렵고, 특정 숫자가 더 잘 나오도록 기울어지지 않게 한 번 더 걸러서 모든 숫자가 같은 확률이에요.

    중복 없이, 또는 중복 허용

    "중복 없이"는 한 번 나온 숫자를 다시 뽑지 않아요. 주사위를 여러 번 던지는 것처럼 같은 숫자가 또 나와도 되면 "중복 허용"을 고르면 돼요.

    이름 추첨

    참가자 명단을 무작위로 섞은 뒤 앞에서부터 당첨 인원만큼 뽑아요. 명단의 몇 번째에 이름을 적었든 당첨 확률은 모두 같아요.

    이럴 때 써요

    경품과 이벤트 당첨자

    댓글 이벤트나 사내 행사 경품 추첨에서 참가자 이름을 붙여넣고 당첨 인원만 정하면 돼요. 결과를 복사해 공지에 그대로 올릴 수 있어요.

    번호와 순서 정하기

    발표 순서, 자리 번호, 출석 번호 중 한 명 고르기처럼 숫자로 정할 일에 써요. 1부터 인원수까지 넣고 인원수만큼 뽑으면 순서가 한 번에 정해져요.

    재미로 뽑는 번호

    "로또 번호" 버튼을 누르면 1부터 45까지 중복 없이 6개를 뽑아요. 재미로 고르는 번호일 뿐, 당첨 확률을 높여 주지는 않아요.

    추첨을 깔끔하게 하려면

    여러 사람이 지켜보는 추첨이라면 시작하기 전에 규칙을 먼저 정해 두는 게 좋아요. 참가자 명단을 확정하고, 당첨 인원과 "한 번 뽑으면 다시 뽑지 않는다"는 원칙을 미리 알려 두면 결과가 나온 뒤에 말이 나오지 않아요.

    화면을 공유하면서 뽑거나, 결과를 바로 복사해 단톡방에 올리면 더 투명해요. 같은 사람이 응모를 여러 번 했다면 명단에 그 횟수만큼 이름을 적으면 응모 수만큼 확률이 올라가요. 한 사람이 한 번만 당첨되게 하려면 이름을 한 번씩만 적으세요.

    자주 묻는 질문

    뽑힌 숫자는 정말 무작위인가요?

    네. 브라우저의 보안 난수 기능으로 뽑고, 특정 숫자로 쏠리지 않도록 걸러내는 방식을 써서 범위 안의 모든 숫자가 같은 확률이에요. 누를 때마다 처음부터 새로 뽑아요.

    같은 숫자가 두 번 나올 수 있나요?

    "중복 없이"를 고르면 나오지 않아요. "중복 허용"을 고르면 주사위를 여러 번 던질 때처럼 같은 숫자가 다시 나올 수 있어요.

    몇 개까지 뽑을 수 있나요?

    한 번에 1개부터 100개까지 뽑을 수 있고, 범위는 -10억부터 10억까지예요. 중복 없이 뽑을 땐 범위 안의 숫자 개수보다 많이 뽑을 수 없어요.

    이름 추첨에서 같은 이름을 두 번 적으면요?

    두 번 적은 만큼 따로 하나씩 세서 당첨 확률이 두 배가 돼요. 응모 횟수만큼 확률을 주고 싶을 때 쓰면 되고, 아니라면 이름을 한 번씩만 적으세요.

    로또 번호를 뽑으면 당첨 확률이 올라가나요?

    아니에요. 어떤 번호 조합이든 당첨 확률은 같아요. 이 도구는 번호를 재미로 골라 주는 것뿐이고, 복권 판매처와는 관계가 없어요.

    입력한 이름은 저장되나요?

    다음에 다시 쓰기 편하도록 이 기기의 브라우저에만 저장돼요. 서버로는 보내지 않아요.
